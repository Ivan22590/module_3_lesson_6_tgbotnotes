# Telegram-бот для командной работы над задачами

Минимальный рабочий Telegram-бот, с помощью которого разные пользователи могут вести **общий список задач**: добавлять задачи, просматривать список и выгружать его в CSV-файл.

## Возможности бота

- Общий список задач для всех пользователей (база данных SQLite).
- Добавление задачи через кнопку или команду, с режимом ожидания текста (FSM).
- Просмотр списка: номер, текст, автор и дата создания.
- Экспорт списка в CSV-файл (UTF-8 с BOM, открывается в Excel).
- Удобный интерфейс через кнопки + команды как дополнительный способ управления.

## Технологии

- Python 3.11+
- aiogram 3.x
- SQLite через aiosqlite (без ORM, простые SQL-запросы)
- python-dotenv (токен из файла .env)

## База данных

- Файл базы: `tasks.db` в корне проекта.
- Создаётся автоматически при первом запуске — ничего настраивать не нужно.

## Установка и запуск

> **В этом проекте окружение уже создано** как `.venv`, зависимости установлены,
> файл `.env` с токеном заполнен. Можно сразу запускать бота (шаги 1–5 ниже —
> для справки или нового окружения):

```bat
.venv\Scripts\python.exe main.py
```

### 1. Создание виртуального окружения

Windows:

```bat
python -m venv venv
```

Linux / macOS:

```bash
python -m venv venv
```

### 2. Активация виртуального окружения

Windows (Command Prompt):

```bat
venv\Scripts\activate
```

Windows (PowerShell):

```powershell
venv\Scripts\Activate.ps1
```

Linux / macOS:

```bash
source venv/bin/activate
```

После активации в начале строки появится `(venv)`.

### 3. Обновление pip

```bash
python -m pip install --upgrade pip
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Создание файла .env

Скопируйте пример файла окружения:

Windows:

```bat
copy .env.example .env
```

Linux / macOS:

```bash
cp .env.example .env
```

Затем откройте `.env` и вставьте свой токен:

```
BOT_TOKEN=your_bot_token_here
```

### 6. Получение токена у BotFather

1. Откройте Telegram и найдите бота **@BotFather**.
2. Отправьте команду `/newbot`.
3. Придумайте имя бота (например, `My Team Tasks Bot`).
4. Придумайте уникальный логин бота вида `my_team_tasks_bot`.
5. BotFather пришлёт вам токен вида `1234567890:AAE...`. Скопируйте его в файл `.env`.

Никогда не публикуйте токен и не записывайте его прямо в код.

### 7. Запуск бота

Убедитесь, что виртуальное окружение активировано, затем:

```bash
python main.py
```

Без активации окружения можно запустить бота так:

```bat
.venv\Scripts\python.exe main.py
```

Остановить бота: `Ctrl + C`.

## Примеры использования

### Команды

| Команда | Действие |
|---|---|
| `/start` | Приветствие и главное меню |
| `/add` | Начать добавление задачи |
| `/list` | Показать список задач |
| `/list_csv` | Выгрузить список в CSV |
| `/cancel` | Отменить текущее действие |

### Кнопки

После `/start` бот показывает главное меню:

- **➕ Добавить задачу** — бот просит прислать текст задачи
- **📋 Список задач** — показывает все задачи
- **📄 Экспорт CSV** — отправляет CSV-файл

На время ввода текста задачи появляется кнопка **❌ Отмена**.

### Сценарий добавления задачи

1. Пользователь нажимает **➕ Добавить задачу**.
2. Бот отвечает: «Отправьте текст задачи одним сообщением.»
3. Пользователь отправляет текст задачи.
4. Бот отвечает: «Задача добавлена.» и показывает главное меню.
5. Задача сохраняется в базу с автором и датой создания — её увидят все пользователи.

Если ввести `/cancel` или нажать **❌ Отмена**, добавление отменяется: «Добавление задачи отменено.»
